# @gastro-saas/web

Next.js (App Router) app for gastro-saas. Part of the pnpm workspace at the repo root — see the
root `README.md` and `docs/architecture/domain-boundaries.md`.

```bash
pnpm dev        # from repo root, or `pnpm --filter @gastro-saas/web dev` from anywhere
```

Hosting target is Cloudflare Pages/Workers, not Vercel — see `docs/architecture/adr/0001-stack-and-modular-monolith.md`.
